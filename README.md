# Repository for my Quest Pro Magisk modules

- AudioFX allows EQ apps to function again system-wide, at the cost of about 150-200ms of extra latency.
  (Wavelet is my personal go-to)

- The LED module adds an idle rainbow cycle to the power LED, and when charging shows the battery percentage via color.
This is also shown for 90 seconds when the device is put to sleep, before disabling completely.
